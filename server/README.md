# ziptassk API

To install dependencies:

```bash
bun install
```

Set `MONGODB_URI` and optionally `PORT` in the server environment, then run:

```bash
bun run start

The API is available at `http://localhost:4000/api/todos` and the health check is at `/health`.
```

This project was created using `bun init` in bun v1.3.14. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
